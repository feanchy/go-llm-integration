# go-llm-integration

## Настройки окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| OPENROUTER_API_KEY | API-ключ OpenRouter | Обязательна |
| OPENROUTER_MODEL | Идентификатор модели | openrouter/free |
| LLM_MAX_TOKENS | Максимальное число токенов ответа | 2000 |

LLM_MAX_TOKENS должна содержать целое положительное число.
При некорректном значении приложение не запускается.
